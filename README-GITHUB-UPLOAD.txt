PHILIP VOULTSOS — ASTRO ACADEMIC PROFILE

This ZIP contains the complete redesigned Astro project. The project files are at the ZIP root: src/, public/, package.json, astro.config.mjs, wrangler.json, and the remaining configuration files.

IMPORTANT: GitHub does not extract an uploaded ZIP into your repository. Extract this ZIP on your computer first, then upload/commit the CONTENTS of the extracted folder to the root of your existing repository. Do not upload the ZIP as a single file.

Keep the existing .git directory if you are using a local clone. This ZIP intentionally does not contain .git or node_modules.

The CV is preserved at:
  public/cv.pdf

Build command:
  npm install
  npm run build

Before deploying, confirm the canonical domain in astro.config.mjs is the domain you intend to use.
